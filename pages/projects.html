I. Publications

DPCexplorer: A Django Web Application for Interactive Exploration of DPCfam and DPCstruct Protein Domain Classifications

Under Review

E. Nyandu Kagarabi, E. Saadat, V. Piomponi

Preprint of a paper under review at the IEEE eScience 2026 conference in Naples, Italy. DPCexplorer takes two very large protein-domain datasets and makes them easy to search in a web browser. It uses a database and a 3D structure viewer, and follows the FAIR principles.

Data Management Django Bioinformatics FAIR

Preprint (DOI)

AI-Powered Early Detection of Dengue Virus Lineages

In Preparation

Emmanuel Nyandu Kagarabi

Extension of my MSc thesis on classification and early detection of Dengue virus lineages with machine learning, developed in collaboration with CERI (Centre for Epidemic Response and Innovation), Stellenbosch University.

II. Software & Data

DPCexplorer (open-source software)

MIT

An open-source Django web app for the DPCfam and DPCstruct datasets, with fast search, file downloads, and a 3D structure viewer. Released on Zenodo so it can be cited and reused.

Software (DOI) GitHub

Preprocessed Datasets for DPCexplorer

Dataset

Clean, ready-to-use versions of the DPCfam and DPCstruct datasets (CSV, FASTA, and PDB files), prepared on the ORFEO HPC cluster and shared as open data.
